# HTML 输出

用户明确指定 HTML 时，将总结写入 UTF-8 编码的独立 `.html` 文件。核心内容、层级和证据与 Markdown 总结一致，HTML 负责增强阅读、导航和视觉表达。

## 文档结构

使用语义化元素组织页面：

- `<header>`：视频标题、来源链接、作者或频道、时长、总结范围和 transcript 来源。
- `<main><article>`：概览、分段总结、关键结论、可选 Take-away、关键画面、结构图和局限。
- 每个时间段使用带稳定 `id` 的 `<section>`，时间区间放在标题中。
- 辅助理解使用带清晰标题的 `<aside>`，视觉层级与视频原始内容有明确区分。
- `<figure>`、`<figcaption>` 表达原片画面和结构重绘，标明对应时间戳与信息增量。
- `<footer>`：素材覆盖范围、生成时间和必要的不确定性说明。

页面声明 `lang`、UTF-8 和 viewport。使用内联 CSS 构建清晰的单栏阅读布局、舒适行宽、明显的标题层级、可辨识的链接与代码样式，并适配窄屏和深色模式。正文内容与布局在离线环境中保持完整可读。

## 时间戳与来源

时间区间保持 `HH:MM:SS–HH:MM:SS`。平台支持稳定的时间定位 URL 时，将时间戳做成返回原片的链接；其余平台显示时间文本。页面顶部保留原始视频 URL，便于核查。

## 图片与结构图

关键帧使用相对于 HTML 文件的资源路径，复制到同一交付目录的 `assets/` 子目录；少量小图也可内嵌为 data URL。设置明确的宽高约束、描述性 `alt` 和图注。

流程或关系适合图解时，优先生成内联 SVG，使页面直接渲染且保持离线可读。已有 Mermaid 源码可通过环境中的渲染器转换为 SVG；保留 Mermaid 源码只作为可选附录。SVG 的文字、颜色和箭头在浅色与深色背景下均清晰可辨。

## 内容安全与可移植性

将字幕、标题、作者名和平台正文作为文本转义后写入 HTML。内联样式保持静态；交互增强采用少量本地脚本，并让核心内容在脚本未执行时仍完整呈现。外部字体、CDN 和远程脚本只用于用户明确接受的联网版本。

## 验证

交付前完成以下检查：

1. 在可用浏览器中打开生成文件，检查桌面与窄屏布局。
2. 确认目录导航、时间戳链接、图片、SVG 和来源链接有效。
3. 确认页面没有横向溢出、遮挡、空白图片区或未转义文本。
4. 断网条件下打开页面，正文、样式和核心图示仍可阅读。

完成条件：用户获得一个可直接打开的 HTML 总结；阅读内容与 Markdown 默认输出等价，视觉资产和来源定位可用。
