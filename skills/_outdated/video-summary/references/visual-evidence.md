# 视觉证据与辅助图

仅在完整读取字幕并确认存在具体视觉信息缺口后读取本文件。调用时应已经具备缺口说明、对应时间范围，以及该画面对总结的重要性。下载和抽帧围绕这些目标进行。

## 进入条件

视觉信息缺口通常满足以下一项：

- 字幕使用“这里”“如图”“看屏幕”“这个结果”等指代，关键对象仍需要画面才能确定。
- 结论依赖图表数值、空间关系、界面状态、代码输出、公式结构或前后变化。
- 无解说或字幕空白区间包含推动内容发展的动作、演示或视觉叙事。
- 用户明确要求关键画面、视觉分析或截图证据。

为每个缺口写一句目标，例如“确认 12:08 图表中两条曲线的相对变化”。目标清单决定抽帧时间点和数量。

## 选择时间点

从字幕与章节中为每个已确认缺口选择一个代表时间点；画面切换较快时再检查前后相邻时间点。优先下载满足目标所需的最低清晰度视频流，并让抽帧数量随缺口数量增长。

抽帧命令：

```bash
python3 <skill-dir>/scripts/acquire_video.py frames '<video-url>' \
  --output '<work-dir>' \
  --timestamps '01:15,04:32,12:08'
```

逐张使用可用的图像查看工具检查。记录画面中实际可见的对象、文字、数值、位置关系和变化，并与字幕对照。时间点偏离目标时，以更精确的时间重新抽帧。

## 在总结中使用

- 原片的图表、界面、代码和实物状态以截图为主要证据，配上时间戳和一句解释。
- Mermaid 适合重绘流程、因果链、角色关系、决策树和层级结构。
- SVG 适合重绘空间布局、带精确标注的结构、时间轴或需要作为独立文件交付的图。
- 重绘内容忠实于视频信息；用“结构重绘”标注其总结性质。原片截图使用“原片画面”标签。
- 每张图都在正文中被引用并解释，确保其提供文字之外的信息。

完成条件：每个已确认的视觉缺口都获得画面证据或明确的缺失说明；最终只保留直接填补这些缺口的截图与重绘图。
