# HTML 输出

用户明确指定 HTML 时，生成一份 UTF-8 编码、可独立打开的 `.html` 文件。内容与同一详略模式下的 Markdown 等价，排版服务于快速阅读。

## Apple Editorial 风格

- 使用纯白页面、接近黑色的正文、单一蓝色强调色和充足留白。可采用 `#ffffff` 页面、`#f5f5f7` 辅助表面、`#1d1d1f` 正文、`#4b5563` 辅助文字、`#d8d8dc` 分隔线和 `#0066cc` 链接。正文与辅助文字优先达到 7:1 对比度；行内链接带下划线，交互元素具有清晰的 hover 与键盘 focus 状态。
- 使用系统字体栈 `-apple-system, BlinkMacSystemFont, "SF Pro Text", "Segoe UI", "PingFang SC", system-ui, sans-serif`。中文正文采用 `17–18px`、400 字重和 `1.65–1.75` 行高；标题采用 600–700 字重。章节主要通过字号、留白和细分隔线建立层级。
- 圆角集中用于确实需要边界的少量容器。时间线面板、关键帧、代码块和重点提示采用 `6–8px`；普通章节、表格和 Take-away 使用直角或 `0–4px`。紧凑的状态标签可以使用胶囊形。阴影保持轻微，主要层次来自 1px 边框与表面色。

## 页面与内容

- 使用 `<!doctype html>`、正确的 `lang`、charset 和 viewport。桌面端让 `<header>`、`<main>` 与 `<footer>` 共用约 `1120–1240px` 的居中容器，可参考 `width: min(1200px, calc(100vw - 48px)); margin-inline: auto`；连续正文保持约 `900–1040px`，图表、关键帧、代码和表格可以使用完整容器宽度。窄屏保留约 `16–24px` 的左右留白。
- 用 `<header>` 呈现标题、原始视频链接、作者或频道、时长和 transcript 来源；用 `<main><article>` 承载概览、分段总结及可选内容；每个时间段使用带唯一 `id` 的 `<section>`；必要信息放入 `<footer>`。分段标题同时包含时间区间与结论型标题；平台支持时间定位链接时，让时间戳可返回原片。
- 时间线目录固定悬浮在 viewport 左侧并脱离正文布局。常态只显示窄触发器；hover 或键盘聚焦时展开分段链接，点击触发器可固定展开或收起。展开期间正文宽度、位置和换行保持稳定。窄屏下让面板宽度受 viewport 约束。
- 使用内联 CSS 完成基础样式和响应式布局。表格、代码、SVG 与图片在各自容器内滚动或缩放，页面宽度保持稳定。关键帧使用相对资源路径，提供描述性 `alt` 和带时间戳的图注；简单结构使用清晰的内联 SVG 重绘。
- 将标题、字幕、作者名和平台正文作为文本转义后写入 HTML。页面保持离线可读，交互只使用少量内联脚本。

默认完成条件是 HTML 文件生成成功并可供用户打开。浏览器验收、截图、像素级调整和额外校验由用户明确要求后执行。
